★Правило: The Passive

be + V3 (Past Participle). Используем, когда важно что сделано, а не кто это сделал. Если нужно назвать, кто сделал — добавляем by: The game was created by experts.
ВремяФормулаПример
Present Simpleam / is / are + V3The game is designed for groups. Prizes are given out.
Past Simplewas / were + V3The game was created by experts. We were invited.
Present Perfecthas / have been + V3This room has been visited by players.
Модальныеcan / must / should + be + V3The game must be finished in one hour. It can't be won.
Как переделать в пассив:
1) Объект из активного предложения становится подлежащим. 2) Глагол: be в том же времени + V3. 3) Кто делал — в конец с by (или совсем убираем: they, people).
They speak English in India. → English is spoken in India.
Отрицание: not после первого вспомогательного — hasn't been taught, wasn't written, can't be played.
